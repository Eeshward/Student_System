EduPredict – Student Performance Prediction System

EduPredict is a web-based Student Performance Prediction System designed to monitor, analyze, and predict students’ academic performance based on marks, attendance, assignments, and assessment results.

The system provides separate dashboards for students and faculty, making academic monitoring and student management easier and more efficient.

🚀 Features

👨‍🎓 Student Module

* Secure-looking student login interface.
* Personalized student dashboard.
* View marks, attendance, and academic performance.
* Predict academic performance based on assessment data.
* View performance charts and improvement suggestions.
* Upload and update profile pictures.
* View academic reports and notifications.

👩‍🏫 Faculty Module

* Separate faculty login.
* Faculty dashboard with class performance analytics.
* Add, update, and delete student records.
* Add, update, and delete faculty records.
* Search students using Student ID or name.
* Monitor marks, attendance, and performance.
* View student performance statistics.
* Generate and export student reports.

📊 Performance Prediction

The system uses a weighted scoring approach to estimate student performance.

Prediction factors:

* Internal examination marks – 50%
* Attendance – 20%
* Assignment performance – 20%
* Previous academic performance – 10%

Performance Categories

Score	Category
85–100	Excellent
70–84	Good
55–69	Average
Below 55	At Risk

Note: This version uses a rule-based scoring formula, not a trained machine learning model.

⚠️ Limitations

This is a frontend demonstration project. Data is stored in browser Local Storage. Login credentials and role-based access are for demonstration only and are not secure production authentication.

For real-world deployment, backend authentication, password hashing, database storage, and server-side authorization are required.
